社交直觉闪卡（Social Intuition Flashcards）

这是一个本地桌面小工具：双击「社交直觉闪卡.pyw」就打开，不需要浏览器，也不需要敲任何命令。
每张闪卡正面是女生提出的问题、调侃、要求或社交情境，背面是对应的标准回复。
练习方式：看到正面后先自己想一句写下来，提交后让 DeepSeek 对比你的回答与标准回复的匹配程度，再查看差距。

一、运行方法（Windows）
1. 需要电脑上装有 Python 3（本工具在 Python 3.13 上开发验证；Real-Social 能双击打开，就说明已经装好了）。
2. 双击本文件夹里的「社交直觉闪卡.pyw」。
3. 首次使用 AI 功能：点右上角「API 设置」，填入 DeepSeek 密钥，点「测试连接」确认可用，再点「保存」。
   如果系统里已经设置过环境变量 DEEPSEEK_API_KEY，程序会自动使用它，无需再填。
4. 关闭窗口即退出程序。

二、三个入口
- 今日复习：只出现 FSRS 判定到期的卡片（新卡也算到期）。做一道：先写回答 → 提交 → 看比对结果 → 点「确认并更新复习计划」，
  之后才写入 FSRS 并计算下次复习时间。不确认就不会改动任何复习数据。
- 自由练习：左侧任选一张卡或点「随机抽一张」。可以重复练同一张、随时换卡；
  无论练多少次，都不会改变下次复习时间、难度、稳定性、正式复习次数，也不写入正式复习队列。
- 全部闪卡：浏览、搜索、筛选、新建、编辑、删除，以及 JSON 导入导出（备份迁移用）。
  修改标准回复只改卡面内容，不会重置这张卡的复习历史；删除卡片会先确认，并明确告诉你同时会清理多少条关联数据。

三、匹配分数与复习计划的关系
- AI 只做一件事：比较「你的回答」与「这张卡的标准回复」在意思和关键内容上的匹配程度，给出 0-100 的匹配度。
- 匹配度再按固定区间换算成 FSRS 评分（界面里也写着）：
    0-39   → 重来（Again）
    40-64  → 困难（Hard）
    65-84  → 良好（Good）
    85-100 → 简单（Easy）
- 这个百分比只代表你的回答与标准回复的接近程度，不代表对你个人的评价，也不是社交能力评分。
- 正式复习：匹配分析成功并经过你确认后，才更新复习计划；分析失败会明确报错，可以重试，绝不会自动猜一个分数糊弄过去。
- 自由练习：只留作答记录，永远不写 FSRS。

四、密钥安全
- 密钥保存在程序文件夹内的相对目录 `data\settings.json`（只在本机，不会上传到其它服务）。
- 请不要把密钥直接写进源码、截屏或发给别人；`data` 文件夹请不要上传或放进公开仓库。
- 如果密钥曾经发到聊天、截图或公开渠道，建议去 DeepSeek 控制台撤销并重新创建。
- 点击提交或「测试连接」时，当前卡片的情境、标准回复和你写的回答会发送给 DeepSeek 用于对比分析；
  请不要输入不希望发送给该服务的内容。

五、本机数据位置
- 所有数据都保存在程序文件夹下的 `data` 子目录：
    data\flashcards.db   闪卡内容、FSRS 调度状态、正式复习日志、作答记录（SQLite 数据库）
    data\settings.json   API 设置（密钥、模型、思考模式）
    data\drafts.json     还没提交的回答草稿
    data\last_error.log  只有在程序启动出错时才会出现
- 想备份或换电脑：用「全部闪卡 → 导出 JSON」，在新电脑上「导入 JSON」即可（可选合并或覆盖）。

六、快捷键
- Ctrl + Enter：提交回答
- Esc：关闭弹窗

七、排错
- 界面右上角显示「未配置 API 密钥」：点「API 设置」填写，或设置系统环境变量 DEEPSEEK_API_KEY 后重新打开程序。
- 401：密钥无效、已撤销或填错。请在 DeepSeek 控制台新建密钥并重新保存。
- 402：账户余额或账户状态问题。429：请求频率或额度受限，稍后再试。
- 网络错误：确认网络可以访问 https://api.deepseek.com。
- 提示「分析失败」时你的回答不会被清空，直接点「重试分析」即可。
- 双击没反应或看不到窗口：打开本文件夹下的 `data\last_error.log` 查看错误，或把该文件内容发给 AI 一起排查。

说明：这是一款社交沟通练习工具，AI 匹配度只是「你的回答和这张卡标准回复」的接近程度，不是对错判分，也不构成现实决策建议。
