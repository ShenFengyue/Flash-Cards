# 社交直觉闪卡

一个放在自己电脑上的小工具，用来练「面对她说的话，我该怎么接」。

打开就是一张卡片：正面是她说的那句话，背面是准备好的回答。你先自己想一句写进框里，提交之后，
AI 会告诉你你的回答和她说的那句话的标准回答差在哪里、差多少。练得多了，临场就不容易卡壳。

它不需要浏览器，也不需要敲命令：双击一个文件就打开了。所有数据都存在自己电脑上。

## 它能干什么

一张卡片 = 一个情境 + 一个好回答。

看到情境，先自己写一句；提交以后，AI 只做一件事：把你写的和卡片背面的标准回答放在一起比，
告诉你哪些意思你抓到了、哪些意思你漏了、哪里明显不一样，最后把标准回答给你看。

三个入口：

- **今日复习**：只出今天该复习的那几张卡。练完点「确认」，它才会记下你这次的状态，算出下次什么时候再复习。
- **自由练习**：想练哪张练哪张，同一张想练几遍都可以，随时换、随时停。它不会影响你的复习安排。
- **全部闪卡**：看所有卡片，搜索，新建，修改，删除，也可以把全部数据导出成文件备份。

第一次打开，里面已经有 5 张示例卡片，可以直接开始练。

## 为什么要做这个小工具

- 很多话不是不会说，而是当时脑子一空，什么都想不起来。把「情境 → 好回答」变成一张张卡片反复过，临场就有话可以接。
- 光自己想是没有反馈的。所以让 AI 来做对照：它不评价你这个人，只说你的回答和标准回答差在哪里。
- 什么时候该复习哪张卡不用自己记。这件事交给成熟的记忆算法（FSRS）去排，你只要打开练就行。

## 怎么用

1. 电脑上要有 Python 3（安装时勾选 `Add Python to PATH`）。不用再装任何别的东西。
2. 双击 `社交直觉闪卡.pyw`，窗口就打开了。
3. 第一次用 AI 前，点右上角「API 设置」，把 DeepSeek 的密钥粘进去，点「测试连接」，通过了就保存。
4. 回到「今日复习」，在框里写下你会说的那句话，按 `Ctrl + Enter`（或者点「提交回答」）提交。

密钥在 platform.deepseek.com 申请。AI 需要联网，按用量计费，一次对比通常只要很少的钱。
如果系统里已经设置过环境变量 `DEEPSEEK_API_KEY`，程序会自动用它，不用再填。

## 你的数据在哪

- 卡片、复习进度、每一次作答，全都存在程序文件夹里的 `data` 目录。
- 只有你做对比的那张卡片内容和你写的回答会发给 DeepSeek，其它数据不出这台电脑。
- 想备份、或者换电脑：在「全部闪卡」里点「导出 JSON」，在新电脑上点「导入 JSON」。

## AI 的分工，一句话说清楚

AI 只比较「你写的」和「卡片背面的标准回答」，不评价你的人格、情商，也不会替你重写答案。
它给的那个百分比，只代表你的回答离这张卡的标准回答有多近，不代表你这个人怎么样。
如果对比失败，它会直接告诉你失败原因让你重试，不会随便编一个分数给你。
